## 🌐 Live Experience

**[Explore Portfolio →](https://swaraj-portfolio-alpha.vercel.app)**

A futuristic, high-tech portfolio website built with React and Vite. This platform showcases a premium user experience featuring 3D animations, scroll-triggered cinematic effects, and a sleek glassmorphism aesthetic.

## ✨ Key Highlights

- **🎬 Video Hover Previews**: Interactive project cards with instant YouTube video previews on hover.
- **🔥 Cinematic Scroll**: Sections smoothly blur and focus using custom scroll-triggered animations.
- **🎭 3D Animated Footer**: Dynamic 3D textured name animation with floating letters.
- **📊 Interactive Skill Bars**: Real-time animated progress bars for technical proficiencies.
- **🌓 Adaptive Theme**: Seamless transition between sophisticated Dark and elegant Light modes.
- **🔍 SEO Perfected**: Optimized with React Helmet Async, automated sitemaps, and structured data.
- **📱 Fluid Responsiveness**: A seamless experience across all device breakpoints.

## 🚀 Local Development

1. **Clone & Navigate**:
   ```bash
   git clone https://github.com/SwarajPrajapati2006/Portfolio.git
   cd Portfolio
   ```
2. **Install**:
   ```bash
   npm install
   ```
3. **Launch**:
   ```bash
   npm run dev
   ```
